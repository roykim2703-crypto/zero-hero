# 제로의 용사

## 1. 게임 개요

### 제로섬 게임

제로섬 게임은 한쪽에서 이득을 보면 그만큼 다른 쪽에 손해가 발생하는
게임을 의미한다.

대표적으로 축구와 농구 같은 스포츠처럼 점수를 얻는 대전게임은 결과적으로
이러한 형식을 띤다.

### 기획 의도

> 플레이어가 게임을 진행하며 자신의 스탯을 서로 바꾸며 적을 돌파하면
> 재밌지 않을까?

### 장르

-   로그라이크
-   RPG
-   플랫포머

------------------------------------------------------------------------

## 2. 기본 진행 구조

게임은 시작 지점에서 던전에 입장하고, 진행 과정에서 나아갈 길을 선택하는
구조를 사용한다.

``` text
시작 지점
   ↓
던전 입장
   ↓
나아갈 길 선택
   ↓
던전 진행
   ↓
다음 선택 및 진행
```

세부적인 분기 구조는 추후 기획에서 확장한다.

## 3. 메인 기믹

이 게임의 핵심은 **스탯을 단순히 증가시키는 것뿐만 아니라, 특정 스탯을
음수로 만들어 상황에 맞게 활용하는 것**이다.

각 능력치는 `+`일 때 일반적으로 관련 능력치가 증가하며, `-` 영역으로
넘어가면 기존 효과가 반전되거나 특수한 효과가 발생한다.

------------------------------------------------------------------------

### 3.1 공격력

공격력이 `-`로 넘어가면 공격이 상대에게 피해를 주는 대신 **상대를
회복시킨다.**

하지만 언데드 계열 적에게는 이 효과가 반대로 작용하여 **강한 피해를 줄
수 있다.**

``` text
공격력 +
→ 일반적인 공격력 증가

공격력 -
├─ 일반 적 → 상대 회복
└─ 언데드 → 강한 피해
```

따라서 적의 특성에 따라 공격력을 양수 또는 음수로 조절하는 판단이
필요하다.

------------------------------------------------------------------------

### 3.2 방어력

방어력이 `-`로 넘어가면 음수가 된 만큼 **받는 피해가 증가한다.**

대신 회복을 받을 때에도 그만큼 **더 많은 회복량을 받을 수 있다.**

``` text
방어력 +
→ 일반적인 방어 능력 증가

방어력 -
├─ 받는 피해 증가
└─ 받는 회복량 증가
```

즉 방어력을 낮추는 것은 위험하지만, 회복 효과를 크게 받을 수 있다는
장점도 존재한다.

------------------------------------------------------------------------

### 3.3 이동 속도

이동 속도가 `-`로 넘어가면 **이동 방향이 반대로 바뀐다.**

공격은 기존의 정방향으로 나가기 때문에 이동과 공격 방향이 서로 달라져
회피와 공격이 매우 어려워진다.

``` text
이동 속도 +
→ 일반적인 이동 속도 증가

이동 속도 -
├─ 이동 방향 반전
└─ 공격 방향은 기존 방향 유지
```

또한 **역방향으로 공격해야 하는 적**도 존재한다.

따라서 이동 방향 반전이 항상 단점으로만 작용하는 것은 아니며, 특정 적을
상대하기 위해 활용할 수 있다.

------------------------------------------------------------------------

### 3.4 크리티컬 데미지

크리티컬 데미지가 `-`로 넘어가면 **크리티컬 발생 시 오히려 데미지가
낮아진다.**

또한 크리티컬 데미지의 반전 효과를 역이용하는 적이 존재한다.

``` text
크리티컬 데미지 +
→ 일반적인 크리티컬 데미지 증가

크리티컬 데미지 -
→ 크리티컬 발생 시 데미지 감소
```

------------------------------------------------------------------------

## 4. 스탯 운용의 핵심

이 게임에서는 단순히 모든 스탯을 높이는 것이 정답이 아니다.

플레이어는 현재 상황과 상대하는 적에 따라 다음 두 가지를 모두 판단해야
한다.

1.  **어떤 능력치를 증가시킬 것인가**
2.  **어떤 능력치를 음수로 바꿀 것인가**

``` text
스탯 선택
   ↓
현재 적과 상황 확인
   ↓
양수 / 음수 상태 결정
   ↓
스탯의 효과 또는 반전 효과 활용
   ↓
적 돌파
```

따라서 일반적인 RPG의 스탯 성장과 달리, **능력치의 양수와 음수를
전략적으로 오가는 것**이 게임의 핵심 기믹이다.
