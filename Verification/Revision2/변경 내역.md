# 화면 수정

- 타이틀의 장식용 영어, 슬로건, 원형 문양을 제거하고 시작/조작법 메뉴와 돌문 장면으로 교체.
- 민트/분홍 중심의 화면을 돌색, 녹슨 천 색, 황동색으로 변경. 증가/감소는 녹색/빨강으로 구분.
- 능력치 카드 세 장을 세 줄의 교환 목록으로 변경. 수치 변화와 음수 효과를 같은 줄에서 확인.
- HUD의 반복 제목과 큰 능력치 패널을 없애고 체력, 방 진행, 재화, 능력치를 간결하게 배치.
- 던전의 원형 문양과 발광 원을 제거. 엇갈린 판석, 균열, 잔해와 횃불로 교체하고 전투 영역을 세로로 확장.
- 상점과 사망/승리 화면의 추상적인 문구를 삭제. 구매 불가 이유를 표시하고 비활성 버튼 문구의 대비를 보정.
- 조작법을 열거나 일시정지했을 때 뒤쪽 UI가 클릭되지 않도록 수정.

Windows 빌드 성공. 능력치 규칙 검증 10,012개 및 기존 실행 검사 33개 통과. 타이틀, 전투, 교환, 상점, 사망, 승리, 조작법 화면을 캡처해 확인했습니다.

기존 Unity 후처리 셰이더 스트리핑/종료 시 버퍼 정리 경고는 동일하게 남아 있습니다. 이번 작업에서 게임 실행 오류는 발견되지 않았습니다.
