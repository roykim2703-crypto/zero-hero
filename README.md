# 제로의 용사

총과 칼을 바꿔 쓰며 20개 맵을 돌파하는 사이드뷰 로그라이크입니다. 맵을 깬 뒤 다음 적을 확인하고, 능력치 하나를 올리는 만큼 다른 하나를 내립니다.

**실행:** `Builds/Windows/ZeroHero.exe`를 더블클릭하거나 Unity에서 `Assets/Scenes/ZeroHero.unity`를 열고 **Play**를 누르세요.

**조작:** WASD 공격 방향 · A/D 이동 · Space 2단 점프 · 클릭 공격 · R 장전 · 1 총 / 2 칼 · Shift 회피 · E 폭탄

상점에서 총 10종과 칼 10종, 소모품과 능력치 강화 아이템을 구매합니다. 능력치 아이템은 가방 3칸에 보관했다가 슬롯을 눌러 이번 도전 동안 해당 능력치를 +1 올릴 수 있습니다. 길 선택과 능력치 교환 중에도 오른쪽 아래 상점 버튼으로 상점을 다시 열 수 있습니다. 일반 맵은 적 종류와 수가 적힌 카드 3장 중에서 선택하며, 보스전으로 향하는 길은 카드 1장만 표시됩니다.

총마다 탄창과 기본 장전 시간이 다릅니다. 이동 속도가 높을수록 장전이 빨라지고, 이동 속도가 0이면 3배 느려지며, 음수면 장전을 시작하거나 진행할 수 없습니다. 전자포는 무한 탄창입니다.

보스는 메두사 → 천사 → 심장 → 바알제붑 → 마왕 순서입니다. 심장은 세 차례 강화되는 적을 소환하고, 소환 중 무적 상태로 피 탄막과 바닥에 누적되는 피 웅덩이를 만듭니다. 사망하면 장비와 능력치가 초기화됩니다.

[무기 수치, 적 특성, 보스 패턴과 빌드 안내](Documentation/제로의%20용사.md)

기획서 반영: **시작 거점 → 던전 입장 → 길 선택 → 전투 → 쉼터 → 다음 길 선택 → 능력치 교환 → 전투**입니다. 음수 방어는 회복도 늘리고, 음수 치명타는 일반 적의 치명타 피해를 줄입니다. 방패병은 후방 공격으로 상대하며, 반전술사는 음수 치명타에 강한 피해를 받습니다.

교환 카드는 일반 교환, 두 능력치 스왑, ±6~10 극단 교환, 다음 전투 동안 한 능력치 ×−1로 구성됩니다. 자금 획득은 1포인트당 동전 가치의 50%만 반영되어 시작 수치 2에서 ×1.0입니다. 사망하면 진행도에 따라 잔재를 받고 기본 능력치를 0.1씩 영구 강화할 수 있습니다. 최고 기록, 누적 기록, 잔재와 영구 능력치는 게임을 종료해도 저장됩니다.
